# Definição de Red Flags (MVP)

Cada regra deve conter definição objetiva, fórmula, threshold, severidade e limitações.

1. Concentração de valor no órgão
2. Concentração de quantidade no órgão
3. Fracionamento em 7/15/30 dias
4. Empresa nova + contrato alto
5. Crescimento abrupto
6. Modalidade de exceção recorrente
7. Outlier de valor
8. Pico de fim de exercício
9. CNAE incompatível (heurística)
10. Fornecedor sancionado
